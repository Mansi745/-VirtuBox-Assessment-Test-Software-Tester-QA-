## About this repo

This repo contains my submission for the QA Assessment Test given by VirtuBox Infotech.
The task was to test a Task Management Application (Registration, Login, Task CRUD, and Input Validation) without executing the app, by writing test cases and listing potential bugs/risk areas.

## What's inside

- Test scenarios & test cases (positive, negative, and edge cases) for Registration, Login, Task CRUD operations, and Input Validation
- 8 potential bugs/risk areas with severity and reasoning, identified without running the app
